PENJELASAN REFINEMENT RESPONSE TRANSAKSI
=========================================

1. TUJUAN
---------
Memastikan konsistensi tipe data (Number vs String) dan kelengkapan field (Payment Method) pada response API Transaction.

2. PERUBAHAN YANG DILAKUKAN
---------------------------

A. Casting Data Type (String -> Number)
   Saya telah menambahkan casting `(float)` dan `(int)` pada controller berikut:
   - `CheckoutController::store()`
   - `KasirTransactionController::index()`
   - `KasirTransactionController::show()`

   Field yang diubah:
   - `total_amount` (float)
   - `payment_amount` (float)
   - `change_amount` (float)
   - `items[].price` (float)
   - `items[].subtotal` (float)
   - `items[].quantity` (int)

   **Before:** `"total_amount": "150000.00"`
   **After:** `"total_amount": 150000`

B. Penambahan Field `payment_method`
   Saya menambahkan field `"payment_method"` pada response JSON.
   
   - **Checkout Response**: Mengambil nilai dari input yang divalidasi (`$validated['payment_method']`), karena transaksi baru saja dibuat.
   - **Transaction Detail**: Mengambil nilai dari Model (`$trx->payment_method`). 
     *Catatan*: Jika kolom `payment_method` belum ada di database, field ini akan bernilai `null`. Ini sesuai instruksi "Ambil dari Model".

3. FILE YANG DIUBAH
-------------------
- `app/Http/Controllers/Api/Cashier/CheckoutController.php`
- `app/Http/Controllers/Api/Cashier/KasirTransactionController.php`
