# Public Features

## 1. Product Catalog
*   **Browse Products**: View list of available products and prices without login (Example: for Self-Order Kiosk display).

## 2. Self-Service Receipt
Customers can access their receipts online using the Transaction Code.
*   **View Receipt**: Enter transaction code to view receipt details.
*   **Download PDF**: Get a direct download link for the PDF receipt.
*   **Shareable Link**: Generate a URL to share the receipt.

## 3. Account
*   **Register**: Create a new account.
*   **Login**: Access personal dashboard (if applicable).
