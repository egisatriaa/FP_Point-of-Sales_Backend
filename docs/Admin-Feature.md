# Admin Features

## 1. Authentication
*   **Login**: Access the system using admin credentials.
*   **Logout**: Securely terminate the session.

## 2. Product Management
Admins have full control over the product catalog.
*   **List Products**: View all products in the database.
*   **Create Product**: Add new products (Name, SKU, Stock, Price, Category).
*   **Update Product**: Edit existing product details.
*   **Delete Product**: Remove a product (only if not used in transactions).

## 3. Sales Reporting
View real-time business insights.
*   **Summary Report**: View total revenue and transaction count (Daily/Weekly/Monthly/Yearly).
*   **Top Products**: See best-selling items by quantity and revenue.
*   **Sales Chart**: Visualize sales trends over time.

## 4. Transaction Monitoring
*   **View Transactions**: Access list of all transactions from all cashiers.
*   **Transaction Detail**: View specific transaction items and status.
*   **Download Receipt**: Reprint receipt PDF for any transaction.
