# Cashier Features

## 1. Point of Sale (POS)
*   **View Products**: Browse available products with stock indicators.
*   **Cart Management**:
    *   Add items to cart.
    *   Update quantities.
    *   Remove specific items.
    *   Clear entire cart.
*   **Stock Validation**: Automatically prevents adding more items than available stock.

## 2. Checkout
*   **Process Payment**: Calculate total, accept payment amount, and calculate change.
*   **Transaction Creation**: Generates unique transaction code and reduces stock stock automatically.

## 3. History & Receipts
*   **My Transactions**: View history of transactions handled by this cashier.
*   **Transaction Detail**: See items sold in a specific transaction.
*   **Digital Receipt**:
    *   View receipt on screen.
    *   Download PDF receipt.
